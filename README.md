# Notes From a Passive-Aggressive Fridge

One funny passive-aggressive note a smart fridge leaves for its owner — dry, petty, and specific. The fridge keeps receipts: it knows exactly how long that yogurt has been sitting there, and it has opinions.

## Run it

```sh
node main.ts
```

Writes one line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
